# SLO nr 5 · Moodboard Astra

Interaktywny moodboard komisji rekrutacyjnej: 16 szablonów Astra Starter Templates, oceny 1–5, wybór finalistów, eksport/import głosów (JSON/CSV). Głosy zapisują się lokalnie w przeglądarce.

Grafiki: wpastra.com / websitedemos.net. Szablony zewnętrzne nie są projektem szkoły.

## Wspólne głosy

Głosy zapisuje skrypt Google Apps Script (`apps-script/Code.gs`) do arkusza „SLO5 Moodboard Astra — głosy komisji” na Dysku szkolnym. Arkusz `Glosy` to dziennik zmian; strona pobiera zestawienie co 30 s.
